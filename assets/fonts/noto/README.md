# Noto Sans

Unmodified static faces from the Google Fonts download of Noto Sans
(https://fonts.google.com/noto/specimen/Noto+Sans), the only UI font of the client.

The faces support Latin and Cyrillic. The copyright notice and the SIL Open
Font License 1.1 are preserved in [LICENSE](./LICENSE), shipped beside the fonts
inside the client JAR. The fonts are loaded from that JAR without installation.
