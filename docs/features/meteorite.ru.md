# Поиск метеоритов

Функция помогает определить **приблизительную область падения метеорита** по нескольким наблюдениям **Star Gaze**.

![Уведомление о падающей звезде](../images/falling%20star.png)

![Линии направлений после первых измерений](../images/meteorite%20triangulation.png)

![Пересечение линий сужает область падения](../images/meteorite%20triangulation%202.png)

Каждое наблюдение задаёт направление или сектор. При сопоставлении нескольких секторов область поиска сужается. Учитывается прогнозируемое время падения.

Результат представляет собой **оценку зоны**, а не гарантированное местоположение метеорита.

Отсчёт на значке звездопада появляется только при действующем серверном прогнозе
после Star Gaze. Если время неизвестно или прогноз истёк, значок остаётся без
чисел. Повторное использование магии позволяет получить новую оценку времени.
