# Map in a separate window

Hearthborn can show the map in its own window, so you can move it to a **second monitor** and keep the whole game screen for the world.

## How to open it

Open the map window and press **Open map in a separate window** in its row of buttons. A window called **Hearthborn map** appears. Drag it to another monitor and make it as large as you like.

- The separate map is **live and interactive**: it shows your position, markers and icons, and you can zoom it with the mouse wheel and double-click it with the left button to return the view to your character.
- Only one such window exists. Pressing the button again brings the open one to the front.
- The window **remembers its size and place**, so next time it opens on the same monitor.
- It uses the same map and markers as the map inside the game, so what you add in one is seen in the other.
- **Invert mouse wheel** (Options → Camera) turns the wheel in this window too.
- Close the window to return to the map inside the game. It also closes when you leave the character.
- While the **combat layout** is on, the separate map hides itself and returns when you leave it.

## Good to know

The picture of the separate map is drawn by the game and copied into the window, so a very large window costs more on weak graphics cards. If the game slows down, make the window smaller.
